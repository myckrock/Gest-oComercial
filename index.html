Como funciona

Você pode importar .XLSX (Excel) ou CSV. O sistema lê a primeira aba da planilha e reconhece diversos nomes e sinônimos para as colunas.

Clientes: nome / cliente / comprador / consumidor; documento / CPF / CNPJ; telefone / celular / WhatsApp; dia; limite / crédito; email / e-mail
Produtos: código / SKU / referência; produto / item / descrição / mercadoria; categoria / grupo; preço / preco / valor / valor de venda; custo; estoque / quantidade / saldo; mínimo; unidade; observações
Preços: código / SKU / referência ou produto / item / descrição; preço / preco / valor / valor de venda; custo
